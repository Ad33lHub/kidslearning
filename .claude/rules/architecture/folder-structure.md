# Rule: Folder Structure

## Top-Level Structure

```
lib/
├── main.dart                          # Entry point only — no business logic
├── core/
│   ├── di/
│   │   └── injection_container.dart  # get_it service locator
│   ├── error/
│   │   ├── failures.dart
│   │   └── exceptions.dart
│   ├── network/
│   │   ├── api_client.dart
│   │   ├── api_endpoints.dart
│   │   └── network_info.dart
│   ├── router/
│   │   └── app_router.dart
│   ├── services/
│   │   ├── audio_service.dart
│   │   └── notification_service.dart
│   ├── theme/
│   │   ├── app_theme.dart
│   │   ├── app_colors.dart
│   │   └── app_text_styles.dart
│   ├── utils/
│   │   ├── constants.dart
│   │   └── extensions/
│   │       ├── string_extensions.dart
│   │       └── context_extensions.dart
│   └── widgets/
│       ├── loading_widget.dart
│       ├── error_widget.dart
│       └── app_button.dart
├── features/
│   ├── home/
│   ├── learning/
│   ├── quiz/
│   ├── video/
│   ├── listen_guess/
│   └── settings/
└── generated/                         # build_runner output only
```

## Feature Module Structure

Every feature follows an identical layout:

```
lib/features/<feature>/
├── domain/
│   ├── entities/
│   │   └── <feature>_entity.dart
│   ├── repositories/
│   │   └── <feature>_repository.dart
│   └── usecases/
│       ├── get_<feature>_list.dart
│       └── get_<feature>_detail.dart
├── data/
│   ├── models/
│   │   ├── <feature>_model.dart
│   │   └── <feature>_model.g.dart    # generated
│   ├── datasources/
│   │   ├── <feature>_remote_datasource.dart
│   │   └── <feature>_local_datasource.dart
│   └── repositories/
│       └── <feature>_repository_impl.dart
└── presentation/
    ├── screens/
    │   └── <feature>_screen.dart
    ├── widgets/
    │   ├── <feature>_card.dart
    │   └── <feature>_list.dart
    ├── providers/                     # or bloc/
    │   └── <feature>_provider.dart
    └── state/
        └── <feature>_state.dart
```

## Assets Structure

```
assets/
├── images/                  # All content images (current structure preserved)
│   ├── 2A.png ... 2Z.png    # Alphabet
│   ├── 80.png ... 89.png    # Numbers
│   ├── 4*.png               # Colors
│   ├── 9*.png               # Shapes
│   ├── 1*.png               # Animals
│   └── ...
├── fonts/
│   └── arlrdbd.ttf
├── icons/                   # App icons (generated by flutter_launcher_icons)
└── animations/              # Lottie JSON files if used
```

## Banned Patterns

```
lib/models/               # BANNED — models belong inside feature/data/models/
lib/screens/              # BANNED — screens belong inside feature/presentation/screens/
lib/controllers/          # BANNED — use providers or blocs
lib/helpers/              # BANNED — use lib/core/utils/
lib/api/                  # BANNED — use lib/core/network/ + feature datasources
```

## File Naming Rules

- All files: `snake_case.dart`
- Screens: `<name>_screen.dart`
- Widgets: `<name>_widget.dart` or `<name>_card.dart` / `<name>_tile.dart`
- Entities: `<name>_entity.dart`
- Models: `<name>_model.dart`
- Use cases: verb-first, `get_<name>.dart` / `save_<name>.dart` / `delete_<name>.dart`
- Repositories (interface): `<name>_repository.dart`
- Repositories (impl): `<name>_repository_impl.dart`
- Data sources (interface): `<name>_datasource.dart`
- Data sources (impl): `<name>_remote_datasource.dart` / `<name>_local_datasource.dart`
